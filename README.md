# Vault — دفتر شخصی و آفلاین دارایی‌ها

طلای آنلاین، شمش، تتر، بیت‌کوین و ریال، هر کدوم به واحد خودش و در هر محلی که هست (صرافی، پلتفرم طلا، کیف پول، خانه…). ارزش کل به سه واحد: **تومان، دلار و گرم طلا**. همه‌ی داده‌ها فقط روی همین گوشی.

## نصب (ریپوی جدا، نه ریپوی FI)

1. در GitHub یه ریپوی **جدید** با اسم `vault` بساز (Public، بدون README).
2. همه‌ی فایل‌ها و پوشه‌های داخل این بسته رو آپلود کن و Commit کن.
3. Settings › Pages › Deploy from a branch › `main` و `/ (root)` › Save.
4. آدرس: `https://نام‌کاربری.github.io/vault/` — در Safari بازش کن › Share › Add to Home Screen.

⚠️ ریپوی FI دست نخوره و فایل بکاپ هیچ‌وقت در ریپو آپلود نشه.

## شروع کار

1. **قیمت‌ها:** گرم طلای ۱۸ عیار (تومان)، تتر (تومان)، بیت‌کوین (دلار). یا متن پیام قیمت رو بچسبون.
2. **محل‌ها:** صرافی، پلتفرم طلا، کیف پول، خانه، هر جایی که دارایی داری.
3. **موجودی اولیه:** برای هر دارایی در هر محل، مقدار و مبلغی که بابتش پرداخت کردی.

## عملیات

| عملیات | کاربرد |
|---|---|
| خرید | از ریالِ همون محل، یا مستقیم از حساب بانکی |
| فروش | ریال همون‌جا می‌مونه، یا به حساب بانکی برداشت می‌شه |
| تبدیل | مثلاً تتر به بیت‌کوین در صرافی |
| انتقال | بین دو محل؛ تفاوت مقدار ارسالی و رسیده = کارمزد |
| واریز / برداشت ریال | جابه‌جایی پول بین حساب بانکی و صرافی یا پلتفرم |
| موجودی اولیه | دارایی‌هایی که از قبل داری |

سود و زیان به روش میانگین قیمت خرید حساب می‌شه، هم به تومان و هم به دلار. در تبدیل، بهای خرید به دارایی جدید منتقل می‌شه.

## امنیت

- **قفل:** از تنظیمات یه رمز عددی بذار. رمز خودش ذخیره نمی‌شه، فقط هش اون.
- **بکاپ رمزدار (AES-256):** بدون رمز بکاپ قابل خوندن نیست. رمز رو جای امن نگه دار.
- **عبارت بازیابی (seed phrase) یا کلید خصوصی کیف پول رو هیچ‌وقت در هیچ اپی یادداشت نکن.**

## لینک‌های میان‌بُر

`#prices` به‌روزرسانی قیمت، `#buy` خرید، `#sell` فروش.

## آپدیت

فایل‌های جدید رو در ریپوی `vault` آپلود کن، اپ رو یکی دو بار ببند و باز کن. داده‌ها دست نمی‌خورن.
